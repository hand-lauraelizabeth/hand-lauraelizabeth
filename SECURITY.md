# Security and privacy

This is a public portfolio repository. It must not contain passwords, API keys, private keys, access tokens, non-public Google Drive URLs, or confidential employer/client/student/member data.

## Reporting a problem

If you notice a security or privacy issue, please do **not** paste sensitive material into a public GitHub issue. Use the contact information on https://www.lauraelizabethhand.com/ instead.

## Portfolio data policy

Public examples should use public-domain, openly licensed, synthetic, or deliberately de-identified data. Source files from employers, clients, students, members, or private Google Drive folders should not be committed directly.

When a Drive-based artifact is appropriate for public portfolio use, publish a reviewed, sanitized export or dedicated public copy rather than linking to the working source file. Remove comments, revision history, hidden sheets/slides, document properties, tracked changes, and unnecessary metadata before publication.

## If sensitive material is committed accidentally

1. Remove it from the repository and Git history.
2. Revoke or rotate any exposed credential immediately.
3. Re-check linked Drive/WordPress copies and sharing permissions.
4. Treat the original secret as compromised even if the commit was later deleted.
