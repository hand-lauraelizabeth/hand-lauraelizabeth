# Stronger Writing: Revision & Proofreading Checklist

A 2026 writing resource for revising from large decisions to small ones.

- [Open the checklist](./Stronger_Writing_Revision_and_Proofreading_Checklist.md)
- Start with purpose, argument, evidence, and structure.
- Move to paragraphs, sentences, tone, and accessibility.
- Proofread only after the substantive revision passes.

## About the approach

The checklist develops a familiar large-to-small revision sequence into a more explicit workflow for argument, evidence, accessibility, factual verification, sentence-level editing, and proofreading. Where established proofreading guidance informs the resource, original sources are credited rather than reproduced.
