# Stronger Writing: Revision & Proofreading Checklist

A publication-safe, newly written 2026 derivative resource for revising from large decisions to small ones.

- [Open the checklist](./Stronger_Writing_Revision_and_Proofreading_Checklist.md)
- Start with purpose, argument, evidence, and structure.
- Move to paragraphs, sentences, tone, and accessibility.
- Proofread only after the substantive revision passes.

## Provenance boundary
The archived 2019 checklist that helped prompt this resource contains externally sourced material and explicitly credits the UNC Chapel Hill Writing Center for part of its proofreading guidance. The archived document is **not** republished here. This resource is an independently rewritten derivative that preserves only the useful workflow concept and standard writing practices.
