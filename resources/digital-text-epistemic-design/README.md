# Digital Text & Epistemic Design

This folder contains a publication-safe derivative resource developed from Laura Elizabeth Hand's documented 2019 collaborative epistemic-design work around the Making and Knowing Project's Digital Critical Edition.

- [Digital Text & Epistemic Design Canvas](Digital_Text_and_Epistemic_Design_Canvas.md)

The public resource is newly authored. It does not reproduce the original Columbia course deliverables, and it distinguishes interface/design methods from claims about deployed software.
