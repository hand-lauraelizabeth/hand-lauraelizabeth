# Decision, Prioritization & Needs-Assessment System

A transparent multi-criteria decision workbook for comparing needs, projects, programs, investments, vendors, or other alternatives without hiding judgment inside a single score.

## Prepared artifact

`Laura_Hand_Portfolio_Decision_Engine.xlsx`

## What it supports

- adjustable weighted criteria;
- higher-is-better and lower-is-better normalization;
- evidence and source fields for scored judgments;
- confidence-adjusted scoring;
- must-have gates;
- base and alternative weight scenarios;
- evidence-coverage and assessment QA;
- scenario comparison and sensitivity testing;
- executive decision-summary output.

The workbook exposes assumptions so users can see **why** a result changes.
