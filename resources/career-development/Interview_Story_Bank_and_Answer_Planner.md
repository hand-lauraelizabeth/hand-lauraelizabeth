## B. Story bank
Create 6–10 reusable stories. Give each a short ID so you can map it to multiple questions.

**Story ID / short name:**  
**Competencies demonstrated:** analysis, leadership, collaboration, communication, problem solving, project management, adaptability, teaching, research, operations, etc.

**Situation / context:**  
What does the interviewer need to know for the story to make sense?

**Task / problem:**  
What outcome, constraint, responsibility, or problem were you addressing?

**Action:**  
What did **you** specifically decide, build, change, analyze, communicate, or coordinate?

**Result:**  
What changed? Include scale, time, money, volume, quality, adoption, efficiency, learning, risk reduction, or other evidence where meaningful.

## I. Evidence quality check
Before relying on a story, ask:
- [ ] Is it true and accurately scoped?
- [ ] Is my individual contribution clear?
- [ ] Can I explain the context without disclosing confidential information?
- [ ] Is there a concrete result or learning outcome?
- [ ] Does it actually answer the question?
- [ ] Can I explain it without jargon?
- [ ] Can I shorten it if the interviewer wants a concise answer?
- [ ] Do I have a different story available so I do not reuse the same example for every question?

## About this resource
Created in 2026, this planner develops recurring interview-preparation methods from Laura Elizabeth Hand’s career-development work into a reusable evidence system rather than a script or answer bank.
