# Career Accomplishment Inventory

A reusable system for recovering evidence from work, school, volunteering, projects, caregiving, community work, and other experience—then translating it into résumé bullets, interview stories, portfolios, performance reviews, and applications.

This develops an accomplishment-identification method present in Laura Hand's archived career-readiness materials: focus on what you did and changed, not merely what your title or job description said.

## 3. Quantification without inventing numbers

Numbers are useful only when they are accurate and meaningful.

Potential evidence:

- [ ] Count — people, projects, records, workshops, partners, courses, documents
- [ ] Rate — completion, conversion, response, attendance, retention
- [ ] Change — before vs. after
- [ ] Time — turnaround, duration, hours saved
- [ ] Money — revenue, budget, savings, cost avoided
- [ ] Frequency — daily, weekly, annual volume
- [ ] Breadth — departments, locations, populations, systems
- [ ] Rank / recognition — only when documented and contextually meaningful

**If I do not have a defensible number, what qualitative evidence demonstrates scope or result?**

## 5. Translate the same evidence for different uses

### Raw fact
What happened?

### Résumé version
Action + what you did + scope/result.

### Interview version
Context + problem + action + result + reflection.

### Portfolio version
Problem + constraints + process + artifact/evidence + result + what you learned.

### Performance review version
Contribution + organizational value + evidence + next opportunity.

### Cover letter version
One concise example selected because it directly supports the role's needs.

## 6. Bullet quality check

- [ ] Does the bullet begin with the contribution rather than generic responsibility language?
- [ ] Is my individual contribution accurate?
- [ ] Is the result supported rather than implied?
- [ ] Is the scale clear where it matters?
- [ ] Have I avoided inflating team outcomes into individual claims?
- [ ] Does the bullet make sense outside my former organization?
- [ ] Have I removed internal acronyms and unexplained jargon?
- [ ] Is every number defensible?
- [ ] Does the evidence belong on this particular résumé rather than merely being impressive?

## 8. Recovery prompts for older work

If you no longer have the original system or deliverable, search for:

- [ ] Old résumés / CVs
- [ ] Email attachments and status updates
- [ ] Meeting agendas
- [ ] Performance reviews
- [ ] Reports and dashboards
- [ ] Presentations
- [ ] Certificates / awards
- [ ] Public webpages
- [ ] Event listings
- [ ] Shared-drive copies
- [ ] Screenshots / photographs
- [ ] Colleague feedback
- [ ] Calendar records
- [ ] Version history

Separate what you remember from what the surviving record proves.

## Development note

This 2026 resource is derived from accomplishment-identification and résumé-development activities found in Laura Hand's archived career-readiness materials, including prompts about training coworkers, recognition, saving time/money/resources, exceeding goals, taking on work beyond a job description, simplifying procedures, leading projects, and community work. It expands that method into a reusable evidence inventory that supports résumés, interviews, portfolios, performance reviews, and archival recovery while adding explicit evidence, confidentiality, and overclaim checks.
