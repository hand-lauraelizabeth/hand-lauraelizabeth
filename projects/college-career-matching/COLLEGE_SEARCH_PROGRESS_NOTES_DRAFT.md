# College Search — visitor-facing progress notes

**Sprint 1 — Public test release:** College Search is now available for public testing, allowing visitors to search and sort 6,243 U.S. institutions using June 10, 2026 College Scorecard data.

**Sprint 2 — Expanded search:** An expanded College Search is in private staging, adding filters for institution type, campus setting, and undergraduate enrollment, with clear information about missing data.
