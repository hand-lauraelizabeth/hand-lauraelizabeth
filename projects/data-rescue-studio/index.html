5. Export original or deduplicated first file

Original input is not changed. Records that differ even slightly are not automatically merged.

Spreadsheet-oriented export prefixes potentially dangerous formula-like cells with a tab. This changes those cell values and is not universally safe across spreadsheet programs. Turn it off for machine-readable CSV and review untrusted data before opening it in spreadsheet software.

For exact decoded cell values and logical source-record positions, export JSON instead. JSON does not add CSV formula prefixes; it is not a byte-for-byte copy or proof of authenticity. For uploaded files, a local SHA-256 fingerprint of the original bytes is included when browser cryptography is available; it can check byte equality, not establish who created the file. If cryptography is unavailable, no fingerprint is claimed. Both downloads contain your data and should be stored privately.
