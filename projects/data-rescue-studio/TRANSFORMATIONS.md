# Reversible changes in Data Rescue Studio

The main review page supports trimming spaces in a chosen column, removing exact duplicate records, and undoing or redoing changes. All edits affect a local working copy. Reconciliation preserves the original logical source record numbers after transformations. Download the operations manifest for a record of actions and counts; it does not contain original cell values and is not a backup. The CSV export contains the current working copy. No file is uploaded.
