# Evidence-Safe Prompt Lab\n\nA browser-based teaching demonstration for building prompts that make evidence boundaries, uncertainty, support classification, counterevidence, and citation integrity explicit.\n\n## What it demonstrates\n- prompt architecture as an evidence contract\n- source-to-claim reasoning\n- overclaim reduction\n- uncertainty labeling\n- counterevidence and verification planning\n- privacy-aware prompting\n\nThe tool runs entirely in the browser and does not call an AI API or transmit entered text. It is designed for instruction and workflow prototyping rather than automated truth determination.\n\nOpen `index.html` in a browser to use the demonstration.\n\n## Design lineage\nThe workflow is adapted from research and revision prompts used to test whether sources substantiate claims, revise language to match evidence strength, and prevent unsupported citations in AI-assisted scholarly work.\n
