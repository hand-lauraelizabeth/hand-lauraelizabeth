# Ethical AI Scenario Auditor

**[Use Ethical AI Scenario Auditor interactively](https://www.lauraelizabethhand.com/resources/learning-curriculum-tools/ethical-ai-scenario-auditor/)** — Opens the working browser interface; no source checkout or installation required.

A browser-based teaching and planning demonstration that turns abstract responsible-AI principles into concrete design questions and mitigation work.

## Review dimensions
Purpose and necessity; data minimization; notice/consent; bias and differential impact; transparency; human oversight; contestability; security; provenance; uncertainty; monitoring; affected-community perspective.

The attention index is deliberately framed as a prioritization aid—not a compliance, safety, or ethics score. The tool also produces a reusable review prompt that asks for risks, mitigations, owners, evidence, and a go/revise/do-not-deploy-yet recommendation.
