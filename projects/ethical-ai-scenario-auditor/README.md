# Ethical AI Scenario Auditor\n\nA browser-based teaching and planning demonstration that turns abstract responsible-AI principles into concrete design questions and mitigation work.\n\n## Review dimensions\nPurpose and necessity; data minimization; notice/consent; bias and differential impact; transparency; human oversight; contestability; security; provenance; uncertainty; monitoring; affected-community perspective.\n\nThe attention index is deliberately framed as a prioritization aid—not a compliance, safety, or ethics score. The tool also produces a reusable review prompt that asks for risks, mitigations, owners, evidence, and a go/revise/do-not-deploy-yet recommendation.\n\nOpen `index.html` in a browser to use the demonstration.\n
