# Standards Check: browser-based reteach grouping tool

A small JavaScript prototype that demonstrates a specific instructional-design decision: group learners by the standard that needs reteaching rather than by total score.

## What it demonstrates

- Vanilla JavaScript and DOM manipulation
- Adjustable mastery-threshold logic
- Standards-level grouping
- Lightweight, no-install browser delivery
- Privacy-conscious portfolio presentation

## Run it

Open `index.html` in any modern browser. The sample class is generated locally in the browser. No learner data is collected or transmitted.

## Evidence boundary

This is a **portfolio demonstration**, not a reconstruction of a documented production deployment. The names and scores are sample data, and this repository does not claim measured classroom impact.

The useful evidence is the design logic: a teacher-facing decision is translated into a minimal interactive tool that makes standards-level grouping explicit and inspectable.
