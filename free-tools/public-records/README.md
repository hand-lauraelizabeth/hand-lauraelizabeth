# Public Records Request Workspace

A browser-local organizer for public-records requests, exact request identifiers, dated communications, and supporting evidence references. No account, remote file upload, automatic submission, legal deadline calculation, or legal determination is required.

Federal FOIA and state/local public-records laws are different. Check the applicable agency instructions before making or following up on a request. The [FOIA.gov how-to guide](https://www.foia.gov/how-to.html) explains federal requests; the [DOJ FOIA Reference Guide](https://www.justice.gov/oip/department-justice-freedom-information-act-reference-guide) explains federal response processes; [NARA guidance](https://www.archives.gov/foia/foia-guide) distinguishes federal archival and operational records.

The tool is intended for private record organization, not for evaluating legal rights or determining compliance. Use synthetic records in public demonstrations.
