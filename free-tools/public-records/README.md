# Public Records Request Workspace

Browser-local organizer for request IDs, agency contacts, event chronology, and evidence source references. No account, upload, automated submission, legal deadline calculation, or legal determination.

Source context: [FOIA.gov guidance](https://www.foia.gov/how-to.html), [DOJ FOIA Reference Guide](https://www.justice.gov/oip/department-justice-freedom-information-act-reference-guide), and [NARA FOIA guidance](https://www.archives.gov/foia/foia-guide). Federal FOIA does not govern state or local public-records requests. Review the applicable agency instructions.

This branch is a review work-in-progress. No production deployment.
