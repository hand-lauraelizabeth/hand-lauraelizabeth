    Only entries matching your current search and filters. The file states which filters were applied.

    CSV contains every entry. Some text can be interpreted as a formula by spreadsheet software. If CSV is unavailable, save JSON to keep the original text.

    Related entries and review summary

    Groups connect entries for your review. A shared group does not establish that sources agree. Long group previews are shortened on screen; JSON keeps the complete text.

    Privacy, saving, and limits

    Your entries stay in this browser tab. Download a JSON copy before closing or reloading. You can reopen it with “Open a saved timeline”.

    Dates use calendar days. The tool preserves your source references, descriptions, and labels. It organizes what you enter; verification and interpretation remain yours.
